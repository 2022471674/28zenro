字符串处理、古典密码、JWT、图片隐写、压缩包分析、Web 信息收集、局域网传输等

## 侧边栏结构

侧边栏只保留**三个工具入口**，具体工具在入口内用顶部 chips 切换（chips 自动换行），
不再一个工具占一条导航：

| --- | --- |

| **Web 安全** | Web 信息收集（JSFinder、Web Fuzz）、指纹探测、内嵌浏览器、HTTP 请求器（Burp 风格常量 / 循环 + 密码学载荷）、多地 Ping、微信凭证校验、SSTI 子类枚举、源码泄露（含目录爆破）、主机探针、端口爆破、MySQL 弱口令审计 |
| **Misc** | 图片工具、压缩包工具、智能翻译、键盘输入模拟、番茄时钟、局域网传输 |

首页 / **快捷访问** / 关于 / 设置仍是独立入口；首页网格按细分分类展示全部工具，
点卡片会自动跳到所属入口并选中该工具。

**快捷访问**是一个链接收藏夹：可以新建自定义分组，把常用站点放进分组，也可以
直接放在「未分组」里。每个链接显示「图标 + 标题」，点击即用系统默认浏览器打开。
新增链接后自动抓取网站 favicon；也可以从本地选择 png / jpg / gif / ico / webp /
svg / bmp / tif 等任意 Qt 支持的图片作为自定义图标，配置与图标缓存保存在用户
配置目录（`config.json` 同级）。

## 一、密码 Fuzz

拿到一段来路不明的密文、又不知道用了哪种算法时，用它一次性把所有能解密的算法跑一遍。

输入三样东西：

| 输入 | 说明 |
| --- | --- |
| **密文** | 要猜的文本，多行也行 |
| **已知 key** | 可选。填了会作为所有带字符串参数的算法的取值（如 SM4 key、异或密钥） |
| **偏移量** | 可选。填了则位移类算法（凯撒 / ROT）**只试这一个值**，留空则遍历整个取值区间 |

跑完后按**可读性**从高到低排序，明文自然浮到最前面：可读性由「可打印字符占比 +
字母 / 汉字占比 + 空格占比 + 高频字母占比 − 符号密度 − 控制字符」加权得出，
低于阈值的结果默认折叠（可勾选「只看可读结果」开关）。双击任意一行即可复制该行结果。

算法取值怎么定：布尔参数两种都试；枚举参数遍历全部选项；整型参数若名字像
`shift` / `offset` / `rot` / `step` / `n` 就按上面的偏移量规则走，否则在
`[最小值, 最小值 + 63]` 区间内遍历（有上限，不会把界面卡死）。

### Fuzz 约定（新增工具必须遵守）

Fuzz 的目标列表**不是写死的**，而是从注册表里自动推导，所以后续新增的密码工具
只要按下面的约定声明，就会自动被收录：

| 工具形态 | 要做什么 |
| --- | --- |
| 双向工具（有 `dec`，加解密互逆） | **什么都不用做**，`ToolSpec.fuzz_participates` 会自动把它算进去 |
| 单向解码器（只有 `enc` 语义，如 URL 解码） | 传 `fuzz=fuzz_decoder(函数)` 显式声明 |
| 参数复杂、需要自定义遍历 | 传 `fuzz=自定义函数(ctx) -> [(标签, 输出), ...]` |
| 明确不该参与（如本身就是 Fuzz 入口、哈希这类不可逆算法） | 传 `fuzzable=False` |

```python
# 双向工具：自动参与，无需声明
ToolSpec(id="rot13", ..., dec=rot13)

# 单向解码器：显式包装
ToolSpec(id="url_decode", ..., fuzz=fuzz_decoder(unquote_text))

# 完全自定义
def _fuzz_sm4(ctx):
    for mode in ("ECB", "CBC"):
        yield mode, sm4_decrypt(ctx.text, ctx.key, mode)

ToolSpec(id="gm", ..., fuzz=_fuzz_sm4)
```

约定落在 `lib/cipher_fuzz.py`（`FuzzContext` / `fuzz_decoder` / `run`）与
`app/registry.py`（`ToolSpec.fuzz` / `fuzzable` / `fuzz_targets()`）里，
新增算法时按上表挑一种即可，不用改 Fuzz 页面本身。

## 三、哈希

**哈希工具**（一个独立页面，标签页切换），单向计算，输入任意文本输出十六进制小写摘要：

| 子标签 | 摘要长度 |
| --- | --- |
| MD5 | 32 位 |
| SHA1 | 40 位 |
| SHA256 | 64 位 |
| SHA512 | 128 位 |
| SHA3-256 | 64 位 |

### MD5 爆破

哈希分类下的**子工具**（在「密码学」入口顶部 chip 切换），由已知 32 位 MD5 反推明文：

- **枚举爆破**：指定长度范围，候选字符集可选纯数字 / 纯字母 / 混合（字母 + 数字 + 特殊符号）；
- **字典爆破**：候选输入池 + 字典文件（项目自带 `dict/` 下的分词字典与 `rockyou.txt`）；
- 支持预测前缀 / 后缀，自动拼接枚举剩余部分；
- 多进程枚举 + 多线程验证，进度日志实时回传，可随时停止；命中后给出明文。

## 四、国密

一个独立页面（三个子标签），覆盖国密算法在 CTF 中的常见用法。算法为**纯 Python 实现**
（`lib/gm_codec.py`），**不引入任何第三方依赖**，全部以 GM/T 官方测试向量自测通过，
便于 PyInstaller 单文件打包。椭圆曲线等耗时运算在后台线程执行，大输入不卡界面。

### SM3 摘要

输入支持**文本（UTF-8）**或**十六进制**两种格式，输出 64 位十六进制摘要。

### SM4 加解密

- **模式**：ECB / CBC（CBC 需填 16 字节 IV，ECB 下 IV 输入框自动禁用）；
- **密钥**：16 字节，支持十六进制（32 位）或 UTF-8（16 字符）录入，可一键生成随机密钥；
- **填充**：可选 PKCS7；
- **输入 / 输出格式**可分别选文本或十六进制，方便在「明文 ↔ 密文」之间来回转换。

### SM2 公钥密码

- **密钥对**：一键生成，或由私钥推导公钥（校验两者是否匹配）；
- **加解密**：密文排列支持 `C1C3C2`（新标准，默认）与 `C1C2C3`（旧标准）；
- **签名 / 验签**：SM3 摘要 + 默认用户标识 `1234567812345678`（可自定义 ID），
  签名为 `r||s` 的 128 位十六进制串；
- 密文输出带 `04` 未压缩点前缀，解密时兼容带 / 不带前缀两种写法。

## 五、进制互转

2 / 8 / 10 / 16 进制**两两互转**（源进制、目标进制各自下拉选择），按 CTF 常见写法做了容错：

- 允许首尾空白，以及数字内部的空格 / 下划线 / 冒号 / 连字符分隔符（如 `1010 1100`）；
- 允许正负号；
- 允许 `0b` / `0o` / `0x` 前缀，但**仅当它与所选源进制一致时才剥离**，避免把 16 进制的 `0B1`（＝十进制 177）误判成二进制前缀；
- 字母大小写均可；输出大于 10 的进制用大写字母，且不带前缀。

| 文本去重排序 / 去重统计 | 见下 |

### 文本对比器



- 差异处按语义高亮：**红 = 仅左侧有（删除）**、**绿 = 仅右侧有（新增）**、**黄 = 两侧不同（替换）**；
- 给出**一致 / 不一致**结论，含差异处数、删除 / 新增单元数、相似度百分比；
- 输入变化后自动对比（350ms 防抖），支持一键交换 A / B、清空。

### 文本去重排序 / 去重统计

- **去重排序**：按**行 / 词 / 字符**三种粒度去重，结果可**保持首次出现顺序**或按**升序 / 降序**排列；可勾选忽略大小写（判重与排序时忽略，输出仍是首次出现的原始写法）。行粒度不改写行尾 `\r` 与行内空白。
- **去重统计**：给出原始单元数、去重后单元数、重复出现次数、重复单元种类、重复率，并按出现次数降序列出重复明细（至多 100 种，超出时汇总提示）。

### JSON 工具

- **解析 / 格式化**：校验 JSON 语法后美化（2 / 4 空格缩进可选）或压缩为单行；
- **结构报告**：输出根类型、键数 / 元素数、最大深度、重复键，以及逐条值的访问路径；
- 语法错误给出 JSON 标准的「**第 N 行第 M 列**」定位；拒绝 `NaN` / `Infinity` 等非法字面量；中文原样保留，不转成 `\uXXXX`；
- **构建器**：选择根节点（对象 / 数组）后逐行编辑「键名 / 类型（字符串 / 数字 / 布尔 / 空值 / JSON 原文）/ 值」生成 JSON，嵌套结构用「JSON 原文」整段插入，也可从解析结果一键导入继续编辑。

## 九、Web 信息收集

### Web Fuzz

输入一个 URL，把页面与主机的信息一次性抓全，再合并成一份 txt 报告：

- **基本信息**：状态码、最终 URL、完整响应头、Cookie、跳转链；
- **安全响应头**：HSTS / CSP / X-Frame-Options / X-XSS-Protection 等单独列出；
- **页面内容**：标题、meta、HTML 注释、表单（action / method / 输入项）；
- **技术栈指纹**：从响应头（Server / X-Powered-By / Cloudflare…）与正文关键词
  （WordPress / Laravel / ThinkPHP / Spring…）识别；
- **信息收集**：同页链接、脚本、邮箱、手机号、IP、主域下子域名；
- **顺带抓取**：robots.txt 与 sitemap.xml（可分别勾选）；
- 结果分区展示在报告面板，点「**合并导出 txt**」把整份报告合并成一个
  `.txt` 落盘；所有请求统一走全局代理池。

### HTTP 请求器

类 **Burp Repeater / Intruder** 的请求发送器 —— 但**不抓包**，直接自己构造并
发送 HTTP 请求。面向 CTF 密码学题：接口参数常常是加密后的密文（Base64 / HEX /
哈希…），需要「换一个密文就发一次请求」看响应差异。

- **请求完全自定义**：方法（GET / POST / PUT / PATCH / DELETE / HEAD …，可
  直接手输任意方法）、URL、查询参数、请求头、请求体（表单 / JSON / 原始文本）
  逐条编辑，**重复键与顺序都保留**（`a=1&a=2` 是两条）。
- **两种载荷模式**：
  - **常量模式**：只发一次，请求里所有 `{{payload}}` 换成「常量值」——把某个
    密文贴进去看响应最方便；
  - **循环模式**：多位置同时替换，四种攻击类型对齐 Burp Intruder：

    | 攻击类型 | 组合方式 | 请求数 |
    |---|---|---|
    | Sniper 狙击手 | 每个位置轮流注入，其余取默认值 | 位置数 × 载荷数 |
    | Battering ram 攻城锤 | 所有位置注入同一个值 | 载荷数 |
    | Pitchfork 草叉 | 各位置各自列表按行并行推进 | 最短列表长度 |
    | Cluster bomb 集束炸弹 | 各位置列表取笛卡尔积 | 各列表长度之积 |

- **载荷位置**：在参数值里写 `{{payload}}` 就被标记为一个位置（同一字段写多个
  就是多个位置）；**一处都不写**时，循环模式自动把每个启用的参数 / 请求头 /
  表单字段的值各当作一个位置，省得手写占位符。「载荷位置」页会实时列出识别到
  的位置与预计请求总数，Pitchfork / Cluster bomb 可为每个位置单独填载荷。
- **密码学接口**（本工具与密码学工具的连接口）：把「载荷列表」的每一行明文
  用一个算法批量加密 / 编码成载荷——Base64 / Base32 / Base58 / Base85 / HEX、
  MD5 / SHA1 / SHA256 / SHA512 / SHA3、凯撒 / ROT13 / ROT47 / 猪圈、URL 编码、
  QP / HTML 实体 / Unicode 转义，以及国密 SM3 / SM4（ECB、CBC，可填密钥与 IV）。
  支持「预览变换」先看结果再替换。
- **不二次编码**：请求报文由工具自己拼装，**载荷按字面发送** —— 已经
  Base64 / URL 编码过的密文不会被二次转义（`+` 不会变 `%2B`、`=` 不会变
  `%3D`），服务器解出来才是对的。「报文预览」可以逐字核对实际发出的报文，
  所以「从 Burp 复制的报文直接贴进来发」也没问题。
- **配置窗口 / 显示窗口分离**：本页只负责「发什么」（方法、URL、参数、请求头、
  请求体、载荷、模式、日志）；点「发送」时自动打开独立的 **「运行结果」窗口**，
  结果表、响应正文、实发报文、请求预览都在那边铺开显示 —— 14/16 英寸小屏上
  配置区保持紧凑不挤压，结果又能放大看；两个窗口可并排、可拖到第二块屏，
  关掉结果窗口后点「结果窗口」按钮随时回来。
- **结果表**：序号 / 载荷 / 状态 / 长度 / 耗时逐行显示，状态码或长度与上一行
  不同时高亮（说明这个载荷「有戏」）；双击看实发报文、响应头与响应正文；支持
  导出 txt、复制载荷列。
- 并发数 / 超时 / 请求间隔 / 是否跟随重定向 / 是否校验证书都可调，所有请求统一
  走全局代理池。

> 主动批量请求请只用于**已授权**目标。

### 微信凭证校验

  逗号分隔均可，空行与 `#` 注释忽略）；
- 结果可复制（制表符分隔）或导出为 CSV；超时可配（默认 15 秒），

### SSTI 子类枚举

针对服务端模板注入（SSTI）点，遍历目标模板引擎 `object.__subclasses__()` 的每个子类，
检查其 `__init__.__globals__` 中是否含 `os` / `system` / `popen` / `eval` /
`__builtins__`，命中即认为该子类提供 RCE 路径：

- **探活**：先注入 `{{1337*7331}}` 确认模板执行点可用；
- **RCE 检测**：服务端 `for + if` 过滤出 globals 里带目标键的子类，输出索引、类名、命中键；
- **利用 payload**：按命中键自动生成 `os.popen('id')` / `system('id')` /
  `eval(__import__('os')...)` / `__builtins__.__import__` 等 payload；
- 支持 GET / POST、附加参数、Cookie、自定义 Header、代理、Object 前缀、
  超时与「额外枚举全部子类」（供人工翻找）；
- 结果可复制 payload 到剪贴板。**仅限授权靶场 / 渗透测试环境使用。**

### 主机探针

（相对端口扫描更不易被防火墙拦截），表格增量展示 **IP / 状态码 / Web 容器 / 标题 / 最终 URL**：

- 线程数可配（默认 10）、请求超时可配（默认 5 秒）；
- 可选 https 探测（默认走 http）；
- 可随时中止扫描；结果可复制或导出为 CSV。

### 指纹探测

输入目标 URL，用与社区工具 [observer_ward（侦查守卫）](https://github.com/emo-crab/observer_ward)
及其指纹库 [FingerprintHub](https://github.com/0x727/FingerprintHub) **兼容的 YAML 指纹规则**做
Web 应用 / 服务指纹识别，识别更细致的项目指纹：

- **三类匹配器**：关键词（`word`，body / header，忽略大小写、`and` 全匹配）、
  正则（`regex`）、favicon 哈希（`favicon`，支持 mmh3 与 md5 双哈希）；
- **版本提取**：规则里的正则 `extractors` 捕获组（`$1` / `$2` / `$name`）自动
  回填 `version` / `info` 等字段；
- **规则库**：内置 `dict/fingerprints/` 一批常见组件指纹（ThinkPHP / Shiro /
  Spring Boot / Struts2 / phpMyAdmin / Nacos / WordPress / Nginx / Tomcat /
  Django / Laravel / Flask…），可「加载规则目录」扩充自定义规则，规则语法与
  observer_ward / FingerprintHub 一致（详见 `dict/fingerprints/README.md`）；
- 结果表格列出**组件 / 产品 / 厂商 / 版本 / 匹配类型 / 证据**，可复制或保存为 CSV；
- 网络请求走全局代理池，后台线程执行，支持随时中止。**仅限授权靶场 / 渗透测试环境使用。**

### 源码泄露

整合 **GitHack / SvnHack / Python-dsstore** 三个工具：只填**域名或带目录的域名**
（`example.com` / `example.com/upload`），工具自动在末尾拼接三条尾路径并逐项检测：

| 尾路径 | 检测内容 | 还原方式 |
| --- | --- | --- |
| `/.git/` | Git 仓库泄露 | 拉 `.git/index`（索引 v2/v3/v4）解析条目，再按 sha1 拉 `objects/xx/…`、zlib 解压并去掉 `blob <size>` 头，按原目录还原源码 |
| `/.svn/` | SVN 工作副本泄露 | 1.6 走 `entries` 递归；1.7+ 拉 `wc.db`（SQLite）查 `NODES`，按 checksum 拉 `pristine/*.svn-base` |
| `/.DS_Store` | macOS 目录索引泄露 | 解析 `DS_Store` 结构取出目录里的文件名，等价于一次目录探测（清单另存 txt） |

- 三项可分别勾选；线程数 / 超时 / 输出目录可配，结果按 `output/leak/<host>/<类型>/` 归档；
- 逐行日志实时滚动，结果表按类型增量填行，可随时停止；
- 已修掉原脚本的问题：GitHack 解压后对 bytes 用正则去头无效、SvnHack 是 Python 2、
  `.DS_Store` 解析无边界检查；另外补了路径穿越校验、单文件 / 总量上限、
  连接失败与「未发现」的区分（前者标红「失败」）。

#### 目录爆破

三条尾路径都没命中时，页面会直接提示「建议继续尝试目录爆破」，下方区域一键开跑：

- **字典默认取 `dict/Contents` 下的全部字典文件**，合并去重后统一测试，
  不用挑文件；目录里现成的词表约 2600 条（目录名 / 文件名 / IIS 路径 /
  源码备份 / 高危入口），目录可另选、可「重新加载」；
- 探测逻辑：先请求一个随机路径拿**基线**，后续响应与基线一致（同状态码、
  同标题、长度接近）的判为「软 404」过滤掉，避免整站返回 200 时满屏假命中；
- 命中按状态码着色（2xx 绿、3xx 蓝、401/403 黄），显示长度与页面标题，
  `Index of /` 这类目录列表额外标注；**双击结果行可直接在浏览器打开**；
- 结果写 `output/leak/dirscan/<host>/hits.csv` 与 `hits.txt`，可随时停止；
- 线程数（默认 16）/ 超时可配，连续连接失败 25 次直接中止并报错。

### 端口爆破

填目标 IP / 域名，选端口来源与代理方式就能跑。**每个端口都从代理池取一个代理，
代理失效或目标对当前出口超时（疑似封禁）立刻换下一个**：

- **端口来源**三选一：内置字典（`dict/Ports`，现成三份：常见端口 178 条 /
  1-1024 全量 1157 条 / 高危端口 79 条）、自定义字典文件、手动范围
  （`1-1024,3306,6379`）；
- **代理方式**三选一：**全局代理池**（默认，复用设置页「Web 工具代理池」的
  免费代理，封禁即换）、代理列表文件（`socks5://h:p` / `http://h:p` /
  `h:p`，一行一个）、直连（对照用）；
- **假代理防护**：走代理前先用保留地址 `192.0.2.1:9` 做一次**否定测试**——
  真代理连它必然失败，而「不管连什么都回成功」的假代理会在这里露馅，
  直接被判死；实测 2223 个公开代理里有 11 个是这种「全通」代理，不做这一步
  会把所有端口都报成开放。池子里全是假代理 / 死代理时扫描会**中止**而不是
  吐假结果；
- 结果只列**开放**端口（端口 / 服务 / 延迟 / 走了哪个代理），双击复制
  `host:port`，写 `output/portscan/<host>/open_ports.{csv,txt}`；
- 「测试代理」按钮可先验证代理池可用数（含假代理剔除统计）；
- 线程数（默认 24）/ 超时（默认 6 秒）/ 换代理重试次数（默认 3）可配。

> 探测只用 SOCKS5 的 `CONNECT` 与 HTTP 代理的 `CONNECT host:port` 建连，
> 不发任何业务数据，探完即关。协议实现是纯标准库手写的，不依赖 PySocks。

### MySQL 弱口令审计

**合规分流**：进入该功能先弹出**强制免责声明**（确认授权后才能操作）。目标按
标准库 `ipaddress` 自动分类：

| 目标类型 | 判定 | 允许的操作 |
| --- | --- | --- |
| 内网 IP（私有 / 回环 / 链路本地） | `10/8`、`172.16/12`、`192.168/16`、`127/8` 等 | 完整弱口令爆破 |
| 公网 IP | 可解析为 IP 且非内网 | 仅纯被动指纹识别 |
| 域名 | 无法解析为 IP | 仅纯被动指纹识别 |

- **纯被动指纹**（公网 / 域名）：只读取服务端主动下发的 HandshakeV10 握手包
  （明文含版本号、认证插件、连接 ID），**不发送任何认证数据**，等价于
  `nmap -sV -p 3306`，全程合规；
- **内网爆破**：协议是纯标准库手写的（不依赖 pymysql / mysql-connector），支持
  `mysql_native_password`（5.x 默认）与 `caching_sha2_password`（8.0 默认，含
  RSA 完整认证）；用户名 / 密码各三种来源（内置字典 / 文件 / 手动）；
- 错误码分语义：`1045` 凭据错误继续；`1129/1130/1203/1040` 立即中止；
  `1049`（未知库）按成功处理；
- 命中凭据绿色高亮，双击复制，导出到 `output/mysql/<host>_<port>/mysql_creds.{csv,txt}`；
- 页面顶部**展示核心脚本文件的 MD5**，若脚本逻辑被篡改（MD5 变化）即会被识别。
  再次声明：请遵守《网络安全法》与平台安全渗透守则，仅对已获授权目标使用，
  因不当使用造成的后果与作者无关。

### 攻击面测绘（一键全链路）

把现有 Web 原子工具编排成一条 pipeline，对单个目标（域名或 URL）按固定顺序
跑一遍并汇总成报告：

```
子域名爆破 → 端口爆破 → 指纹探测 → WAF 识别 → 目录爆破 →
源码泄露 → 参数爆破 → OSS 桶探测
```

- 每一步都有**独立开关**（重资源步骤「端口 / 目录 / 源码泄露」默认关闭，
  子域名 / 指纹 / WAF / 参数 / OSS 默认开启），避免误伤目标；
- 全程后台线程执行、可随时停止；单步失败不影响后续步骤；
- 结果按「步骤 + 结果 + 摘要」表格展示，可一键复制成文本报告；
- 底层**复用 `lib` 现有纯函数**（`dns_tool` / `port_scan` / `fingerprint` /
  `waf_detect` / `dir_scan` / `leak_scan` / `param_fuzz` / `oss_bucket`），
  不重复实现算法。

### WAF 识别

输入目标 URL，对比正常请求与带攻击特征请求在状态码 / 响应头 / 响应体上的差异，
结合内置指纹识别常见 WAF 厂商（Cloudflare / 宝塔 / 安全狗 / ModSecurity / D 盾 /
云锁 / 阿里云盾 / 创宇盾等），命中后附带常见**绕过建议**（分块传输、编码混淆、
注释穿插等）。

### OSS 桶探测

检测阿里云 OSS / 腾讯 COS / AWS S3 桶的越权访问：

- 可手动填桶名列表，或填主域名自动派生候选桶名（`域名-oss` / `域名-backup` 等）；
- 对每个桶逐厂商探测「**公开读 / 可列举（ListBucket）/ 桶存在**」三种状态；
- 只做匿名只读探测，不写入、不爆破，命中即提示配置风险。

### 弱口令检测（Redis / FTP / SSH）

与 MySQL 弱口令互补，覆盖内网授权测试中同样高频的几类服务（纯标准库手写协议，
无第三方依赖）：

| 服务 | 能力 |
| --- | --- |
| Redis | 密码爆破（含空密码 `PING` 检测，区分「无密码」「密码错」） |
| FTP | 用户名 × 密码爆破（`USER` / `PASS`，230 成功 / 530 拒绝） |
| SSH | 仅被动 banner 指纹（读 `SSH-2.0-xxx` 版本串，不爆破） |

- 目标分类沿用 MySQL 的合规边界：**内网可爆破，公网 / 域名仅被动指纹**；
- 内置常用弱口令字典（比 rockyou 小得多，日常授权测试命中率足够），也支持手输。

### Web 工具代理池

设置页「**Web 工具代理池**」给所有走 HTTP 请求的 Web 工具提供统一代理转发：

- **免费代理源**：内置 5 个已验证的免费源（TheSpeedX http/socks5、proxifly http、
  openproxylist socks5、monosans socks4），可勾选启用、也可手填代理（每行一个
  `ip:port`，可带 `socks5://` 前缀）；
- **迁移自 fir-proxy 的核心逻辑**：拉取（fetcher）→ 验证（checker：TCP 预检 +
  实际转发 + 保留地址否定测试识别「全通」假代理）→ 轮换（rotator 游标轮换、
  故障剔除）；
- **使用前检测**：启用后 Web 工具（Web Fuzz / JSFinder / 主机探针 / 源码泄露 /
  目录爆破 / 端口爆破 / 指纹探测等）自动绑定轮换代理；池空时先尝试拉取免费源一次，失败则**回退直连**，
  不影响工具正常使用；
- **代理持久化**：拉到可用代理后立即写入 `config.json` 的 `proxy_pool.cache`，
  下次启动直接恢复、无需重复拉取；直到这些代理全部失效（被判死）才需要重新
  获取；
- 配置持久化在 `config.json` 的 `proxy_pool` 节，可设置优先协议（http/socks5/
  socks4）、验证超时、验证线程、拉取上限。

> 免费代理源不稳定、失效快属正常现象；池内可用数偏少时可在设置页点「获取并检测代理」
> 重新拉取，或填手动代理。
>
> **新增 Web 工具的约定**：所有需要发 HTTP 请求的 Web 工具，都必须经
> `lib.proxy_pool.make_session()`（或 `apply_proxy()`）创建会话，从而「启用代理池即全局
> 生效」。**内置浏览器是唯一例外**（它走自己的 QtWebEngine 网络栈）。不要在 Web 工具里
> 自己 `requests.get` 或新建绕过代理池的会话。

## 十一、局域网传输

点「开启服务」即在本机 `0.0.0.0` 上起一个 HTTP 服务，并自动建一个频道、生成
**4 位数字密码**；同网段的手机 / 电脑用浏览器打开回显的地址，选频道 + 输密码
即可加入该频道，上传 / 下载文件。本机也能作为客户端，填对方的 `IP:端口`
拉取频道列表、输密码加入别人的频道。

- **一个频道一套密码**：可建多个频道，每个频道独立的 4 位密码与独立目录；
  每次加入都要重新输密码，会话 2 小时过期，主动退出立即作废；
- **连续输错 5 次锁定 5 分钟**，避免被逐个数字试出来；
- 浏览器端支持**拖入 / 多选上传**（带进度条）与自动刷新的文件列表，
  桌面端支持多选上传 / 下载并显示实时进度；
- 本机侧可复制密码、重置密码、删除频道、把本机文件直接发进频道；
- 文件名统一清洗（杜绝路径穿越），重名自动追加 ` (2)`，存储目录为
  `output/lan_share/<频道名>`，可在页面一键打开。

> Windows 首次开启会弹防火墙授权，需要允许「专用网络」访问，否则同网段设备连不上。

## 十二、工具箱

### 键盘输入模拟

按设定**速率与时长**向当前焦点窗口持续注入按键：

- 所有按键事件以「**扫描码 + KEYEVENTF_SCANCODE**」下发，与真实物理键盘上报一致，模拟器 / 游戏等只认硬件扫描码的软件同样有效；
- 支持特殊键名（`{ENTER}` / `{TAB}` / `{F1}` 等）；
- 开始前有倒计时以便切换到目标窗口；
- 检测到前台窗口属于反作弊保护的进程时会明确拦截提示。

### 图片工具

| 子工具 | 说明 |
| --- | --- |
| 添加可见水印 | 载体图片 + 水印文字，位置 / 字号 / RGBA 颜色 / 字体可调，支持四角定位与整图平铺；重名文件自动加后缀不覆盖 |
| 隐写嵌入 | 把秘密信息写入图片 **LSB** 通道（输出强制 PNG，JPEG 压缩会破坏数据） |
| 提取水印文字 | 从隐写图片读回水印 / 秘密信息，可同时保存到输出目录 |
| 图片转 Base64 | 图片编码为 Base64 文本，可选 Data URI 前缀，可复制或保存为 txt |
| Base64 转图片 | Base64 文本还原为图片文件，支持 Data URI 前缀 / 折行 / URL-safe 字母表，扩展名按实际类型自动补全，保存到输出目录 |
| OCR 文字识别 | 调用设置中配置的 OCR 模型（OpenAI 兼容多模态接口）识别图片文字，可复制或保存为 txt |

中文等多字节字符按 UTF-8 字节写入，避免逐字符拆位导致的错位。
输出位置统一在设置中自定义（默认应用根目录下的 `output` 文件夹）。

### 压缩包工具

| 子工具 | 说明 |
| --- | --- |
| 伪加密修复 | 识别 ZIP 通用标志位被置 1 但数据并未真正加密的「伪加密」包，一键清除标志位生成修复副本（保留原压缩方式与元数据）；真加密包会明确提示需要密码，而不是硬改 |
| CRC32 碰撞 | ZIP 条目记录的 CRC32 是**未压缩明文**的校验和；对 ≤6 字节的小文件直接枚举字符集碰撞还原明文，无需密码。可自动扫描包内小文件，也可手动指定 CRC 与长度，并带搜索空间护栏与字符集预设 |
| 字典爆破 | 内置常用密码字典 + 0~N 位纯数字字典，也可选用自定义字典（如项目自带的 `rockyou.txt`）；后台线程执行、可随时停止，命中后可直接解密提取 |

对每个候选密码只做一次「打开首个加密条目读 1 字节」的校验，不做全量解压，
既快也不会污染磁盘。输出位置统一在设置中自定义。

## 十三、JWT

### JWT 工具

覆盖 JWT 的完整生命周期：

- **解析 / 校验**：拆出 Header / Payload / Signature，填入密钥可校验签名真伪，识别的注册声明附带中文说明，可一键转到修改页；
- **创建**：选择算法 + 自定义密钥，逐行编辑 `iss` / `sub` / `exp` 等声明（时间类声明自动预填），一键生成令牌；
- **修改 / 重签**：载入已有令牌，增删改声明后按原算法或指定算法重新签名。

支持的算法：**HS256 / HS384 / HS512**（HMAC）、**RS256 / RS384 / RS512**（RSA PKCS1v15）、
**ES256 / ES384 / ES512**（ECDSA）、**none**（CTF 常见的 `alg:none`）。

声明值做智能类型识别：`true` / `false` → 布尔，纯数字（如 `exp` 时间戳）→ 整数，
`{...}` / `[...]` → JSON 对象 / 数组，其余按字符串保留。
ECDSA 系列在内部自动完成 **DER ↔ 裸 `R||S`** 双向转换并校验曲线匹配
（JWT 规范要求裸签名，而多数密码库产出 DER，这是个经典坑）。

### 命令行调度入口（CLI）

除桌面 GUI 外，还提供 `cli.py` 命令行入口，可把 Web 类工具以命令行方式拉起来跑、
返回结果，用于脚本化、批量处理与 CI 集成（无需安装 PySide6）：

```bash
python cli.py list                          # 列出全部工具（标注 CLI 可用 / 仅 GUI）
python cli.py webfuzz https://example.com   # Web Fuzz（加 --robots 等开关）
python cli.py dns example.com               # DNS 解析
python cli.py fingerprint https://x.com     # 指纹探测
python cli.py portscan 1.2.3.4 --ports 1-1024
python cli.py ... --json                    # 输出结构化 JSON（供脚本 / Agent 消费）
python cli.py ... --config <path>           # 指定 config.json（默认用户数据目录）
```

CLI 与 GUI 共用同一套 `lib` 纯函数与全局代理池配置（`config.json`），行为一致。
每个子命令名与 GUI 工具 id 一一对应，可用 `python cli.py <子命令> --help` 查看参数。
当前已接入的 Web 工具：`webfuzz` / `jsfinder` / `fingerprint` / `dns` / `subdomain` /
`hostsearch` / `httpscan` / `dirscan` / `leakscan` / `paramfuzz` / `portscan` /
`ssti` / `wechat` / `ping`。

打包（可选）：

```bash
pyinstaller 28zenro.spec --noconfirm
```

产物为单文件 `dist/28zenro.exe`，图标与内置字典随包分发。
